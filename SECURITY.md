# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **morooka@oobe-io.com**.
Do not open a public issue or post in the WordPress.org support forum.

Include the Unbox version, steps to reproduce, and the impact you expect. We will acknowledge your report as soon as we can and release a fix before disclosing details.

## Supported versions

Only the latest release receives security fixes.
